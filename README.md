# 序库 · 个人案件管理平台

序库是一个在浏览器中使用的个人案件管理工具，帮助使用者整理社会案件、银行案件、办案进度和回款记录。数据保存在当前浏览器中，无需部署服务器。

## 主要功能

- **社会案件**：记录案件信息，按状态筛选和搜索；查看近期工作节点、案件状态及执行情况。
- **银行案件**：按银行、案件类型和被告案件分层管理，查看案件状态、执行情况及近期节点。
- **办案进度**：为案件记录时间点或时间段事项，通过时间线和甘特图查看进度。
- **回款管理**：逐案登记标的回款和律师费回款，并查看汇总情况。
- **数据管理**：将案件及进度导出为 JSON 备份，从备份恢复，或经两次确认清空数据。

## 开始使用

需要支持 JavaScript 和本地存储的浏览器。取得项目文件后，在浏览器中打开根目录的 `index.html` 即可使用，无需安装依赖或配置环境变量。

## 使用方法

1. **新增社会案件**：在“社会案件”点击“新增案件”，填写并保存信息。双击案件行进入详情；点击字段可编辑，离开字段后自动保存。
2. **跟踪社会案件进度**：在案件详情点击“新增阶段”，填写时间点或时间段事项；使用“时间线”和“甘特图”切换视图。
3. **管理银行案件**：进入“银行案件”，点击“新增业务分组”，再在分组内新增被告案件。进入案件进度后可新增进度事件，也可打开“回款管理”登记款项。
4. **备份或恢复**：进入“数据管理”，点击“导出 JSON 备份”，确认文件已保存。恢复时点击“选择备份文件”，选择此前导出的 JSON 文件。

## 数据与使用注意事项

- 案件资料保存在当前浏览器的本地存储中，不会自动同步到其他浏览器或设备。清除浏览器数据、更换浏览器或设备可能导致无法访问原有资料；请定期备份，并保护备份中的敏感信息。
- 导入备份会覆盖对应的现有数据，操作前应先导出当前备份。旧版仅含社会案件的备份导入时，现有银行案件予以保留。清空数据无法撤销。
- 日程和期限展示以录入日期为依据，不自动认定法定期限；时间段的进度表示时间经过比例，不代表实际办案完成度。具体期限应结合案件自行核对。
- 银行案件状态可以多选，其状态分布按状态标记数计算；标的和律师费回款分别统计，汇总包含超额回款。

## 自检

自检需要 Node.js。在项目目录执行：

```bash
node self-check.mjs
```

脚本检查数据兼容、保存保护、统计和页面行为等逻辑；日常使用平台不需要运行该脚本。
