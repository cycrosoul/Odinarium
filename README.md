# Odinarium · 序库

一个在浏览器中使用的个人案件管理工具，用于记录普通案件、银行案件、办案进度和回款情况。应用主体为单个 HTML 文件，无需安装依赖或部署服务器。

## 项目简介

本项目面向需要自行整理案件的使用者，将案件信息、办案进度和银行案件回款集中记录在本机浏览器中。

## 主要功能

- **普通案件**：录入、编辑、搜索和按状态筛选案件，查看临近日程及办案进度。
- **银行案件**：按银行和案件类型分组，逐案管理被告信息、进度和回款；分别统计标的回款与律师费回款。
- **进度跟踪**：记录时间点和时间段，查看时间线、甘特图及临近日程。
- **数据管理**：导出和导入 JSON 备份，或经两次确认清空数据。

## 开始使用

需要支持 JavaScript 和本地存储的浏览器。取得项目文件后，用浏览器打开根目录的 `index.html` 即可；无需安装依赖、配置环境变量或启动服务器。

## 使用方法

1. **录入案件**：在“案件总览”点击“新增案件”填写信息。银行案件则进入“银行案件”，先新增业务分组，再在分组内新增被告案件。
2. **记录进度**：在案件列表点击进度按钮或双击案件行，添加办案阶段；银行案件可添加进度事件。可在时间线和甘特图之间切换。
3. **登记回款**：在银行业务分组内的被告案件上点击“回款”，填写金额和款项归属。
4. **备份资料**：进入“数据管理”，点击“导出 JSON 备份”，将文件妥善保存；需要恢复时选择备份文件导入。

## 数据与备份

案件资料保存在当前浏览器的本地存储中，不会自动同步到其他浏览器或设备。清除浏览器数据、更换设备或浏览器可能导致无法访问原有资料，请定期导出备份，并以适当方式保护其中的敏感信息。

导入备份会覆盖对应的现有数据，操作前请先导出当前备份。旧版仅含普通案件的备份导入时，现有银行案件予以保留。清空数据无法撤销。

页面展示的日程以录入日期为依据，不会自动认定法定期限；请结合具体案件自行核对期限。

## 项目文件

- `index.html`：平台主页面，包含界面、样式和业务逻辑。
- `self-check.mjs`：无需额外依赖的自检脚本；安装 Node.js 后，可在项目目录运行 `node self-check.mjs`。
- `PROJECT_LOG.md`：功能变更、数据兼容和维护记录。
- `办案进度样例.html`：办案进度页面样例。
- `docs/`：项目设计资料。
