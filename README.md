# 序库 · 个人案件管理平台

序库是一个在浏览器中使用的个人案件管理工具，帮助使用者整理社会案件、银行案件、办案进度和回款记录。案件数据保存在当前浏览器的本地存储中，无需部署服务器。

## 功能概览

- **社会案件**：记录当事人、案号、受理机关和案件状态，搜索案件并查看近期工作节点。
- **银行案件**：按所属银行和案件类型建立业务分组，管理分组内的被告案件、进度和回款。
- **办案进度**：记录时间点或时间段事项，查看案件历程、临近日程和需要关注的事项。
- **统计信息**：查看案件状态和执行情况；银行案件另有标的回款、律师费回款汇总。
- **数据管理**：导出和导入 JSON 备份，或清空本浏览器中的案件数据。

## 开始使用

需要支持 JavaScript 和本地存储的浏览器。取得项目文件后，双击根目录中的 `index.html`，或用浏览器打开该文件，即可进入平台。日常使用无需安装依赖、配置环境变量或启动服务器。

页面包含“社会案件”“银行案件”和“数据管理”三个入口。首次使用时可以先录入一宗案件，再添加进度和导出备份。

## 社会案件

### 新增和查找案件

1. 进入“社会案件”，点击“新增案件”。
2. 填写案由、案号、委托人、对方当事人、受理机关和案件状态等信息，点击“保存案件”。案件状态为已判决或已调解时，还可设置执行状态。
3. 在列表上方输入案号、案由、当事人或受理机关等关键词搜索；也可用状态选项筛选。列表支持翻页和横向滚动。

首页的“近期工作节点”展示各案件最近的未来节点；“执行情况”仅统计已判决或已调解案件，“案件状态分布”按案件状态统计。

### 编辑案件和记录进度

1. 双击案件行进入案件详情；也可选中案件行后按回车。
2. 在“案件信息”中点击字段进行编辑，离开字段后自动保存。
3. 点击“新增阶段”，选择常用办案事项或自定义事项，填写事项名称、日期、状态和备注。时间类型可选时间点或时间段；时间段的结束日期不能早于开始日期。
4. 在“案件历程”查看记录，并使用记录旁的编辑或删除按钮维护阶段。“需要关注”区域展示即将发生或长期期限等事项。
5. 点击“返回社会案件”回到列表。列表中的删除按钮会删除案件及其全部阶段，确认前请核对。

## 银行案件

### 建立业务分组和录入被告

1. 进入“银行案件”，点击“新增业务分组”，选择所属银行、案件类型并按需填写备注，保存分组。
2. 在分组卡片点击“管理案件”，再点击“新增被告案件”。
3. 填写被告、案号、联系方式、地址、银行经办人、标的额、律师费、案件状态及备注等资料后保存。案件状态可以多选；已判决或已调解时可以设置执行状态。
4. 在银行案件页面可搜索案件类型、经办人、被告或案号，并按银行筛选。使用分组选择框或前后按钮切换分组，也可在卡片上拖动切换。

分组卡片提供管理、编辑和删除操作。**删除分组会一并删除组内被告案件、回款和进度**；删除被告案件也会删除其回款与进度记录。

### 跟踪进度

1. 打开分组的“管理案件”，在被告案件行点击“办案进度”按钮，或进入该案件的进度页面。
2. 点击“新增进度事件”，选择常用事项或自定义事项，填写时间类型、名称、日期、状态和备注后保存。时间段的结束日期不能早于开始日期。
3. 在案件历程中查看、编辑或删除事件。页面上的查找框和案件选择框可用于切换被告案件；“编辑案件”可修改当前案件信息。

### 登记回款

1. 在被告案件的办案进度页面点击“回款管理”。
2. 填写回款日期、金额，选择“标的回款（贷款本息）”或“律师费回款”，再选择回款方式并按需填写备注，点击“添加回款记录”。
3. 在回款明细中核对记录；错误记录可删除后重新添加。页面分别展示标的累计回款、标的未回、律师费已收及待收等信息。

银行案件首页分别汇总标的回款和律师费回款，包含超额回款。案件状态可多选，状态分布的环形占比按状态标记数计算；执行情况仅统计已判决或已调解案件。

## 备份、恢复与数据安全

- **导出**：进入“数据管理”，点击“导出 JSON 备份”，确认浏览器已将文件保存到安全位置。备份包含社会案件、银行案件及其进度记录。
- **恢复**：先导出当前数据，再点击“选择备份文件”，选择此前导出的 JSON 文件，核对提示中的数量后确认。导入会覆盖备份中对应的现有数据；旧版仅含社会案件的备份不会覆盖现有银行案件。
- **清空**：点击“清空全部数据”并连续确认两次，将删除社会案件和银行案件资料，无法撤销。操作前请确认备份可用。

数据不会自动同步到其他浏览器或设备。清除浏览器数据、更换浏览器或设备可能导致无法访问原有资料。建议定期导出备份，并妥善保护其中的当事人和案件敏感信息。

页面显示的日程以录入日期为依据，不自动认定法定期限。时间段的进度表示时间经过比例，不代表实际办案完成度；具体期限应结合案件自行核对。

## 项目文件与自检

| 文件或目录 | 用途 |
| --- | --- |
| `index.html` | 平台页面、样式与业务逻辑 |
| `self-check.mjs` | 自动自检脚本 |
| `PROJECT_LOG.md` | 功能变更与维护记录 |
| `办案进度样例.html`、`办案进度视图样稿.html` | 进度页面样例和视图样稿 |
| `docs/` | 项目设计资料 |

维护项目时，安装 Node.js 后可在项目目录运行：

```bash
node self-check.mjs
```

该脚本检查数据兼容、保存保护、统计及部分页面行为。日常使用平台不需要运行它。
